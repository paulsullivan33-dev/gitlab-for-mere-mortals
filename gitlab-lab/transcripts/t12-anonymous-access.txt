# What the instance tells a stranger. Two requests with no
# token at all, against the running instance:

$ curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:8929/api/v4/user
HTTP 401

$ curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:8929/api/v4/projects/1
HTTP 404

# 401 for "who are you" — the API refuses to identify anyone
# without a credential. 404, not 403, for the private
# project: GitLab answers as if the project did not exist,
# so an outsider cannot even learn that it is there.
# Chapter 8 leans on both numbers.
