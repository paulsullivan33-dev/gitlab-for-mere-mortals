# The one configuration file an administrator ever edits is
# generated from this template by the package's post-install
# script (read in full by the lab):

$ wc -l /opt/gitlab/etc/gitlab.rb.template
3849 /opt/gitlab/etc/gitlab.rb.template

# And the post-install script itself, reduced to its actions:
#   1. symlink the gitlab-ctl commands into place
#      (embedded/bin/symlink_ctl_cmds)
#   2. copy etc/gitlab.rb.template to /etc/gitlab/gitlab.rb
#      with the external URL filled in
#   3. run: gitlab-ctl upgrade   (which reconfigures the stack)
# The lab follows the same steps by hand in transcript t04,
# with one change: the configuration is written small and
# deliberate instead of copied from the 2,940-line template.
